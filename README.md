# KABI Consulting

Site statique personnel pour présenter des services de consultance en informatique et gestion logistique.

## Fichiers

- `index.html` : contenu de la page
- `styles.css` : mise en page et design responsive
- `script.js` : menu mobile, année automatique et icônes
- `assets/hero-consulting.png` : visuel principal du site

## Publication gratuite sur GitHub Pages

1. Créer un dépôt GitHub, par exemple `kabi_consulting`.
2. Ajouter ces fichiers dans le dépôt.
3. Aller dans `Settings` puis `Pages`.
4. Choisir la branche `main` et le dossier `/root`.
5. Enregistrer.

GitHub donnera une adresse du type :

```text
https://votre-nom.github.io/kabi_consulting/
```

Pour un site personnel principal, le dépôt peut aussi s'appeler :

```text
votre-nom.github.io
```

Dans ce cas l'adresse sera :

```text
https://votre-nom.github.io/
```
